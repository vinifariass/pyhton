Here are the four conditions we need to check for the spy:
  • The first letter of the first name and the first letter of the last name must be the same.
  • The age must be between 20 and 30 (inclusive).
  • The pet name must end in "y".
  • The height must be greater than 170 cm.
We are going to leave this project a little more open-ended than usual. but if you feel like you want to add more conditions, go for it!
